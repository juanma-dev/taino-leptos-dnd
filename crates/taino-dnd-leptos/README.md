# taino-dnd-leptos

Accessible, pointer-events drag-and-drop for [Leptos](https://leptos.dev).

> ⚠️ **Pre-alpha.** Stage 1 (functional MVP) is in progress. Public APIs will change.

```toml
[dependencies]
taino-dnd-leptos = "0.0.1"
```

Built on top of [`taino-dnd-core`](https://crates.io/crates/taino-dnd-core),
which contains all framework-free logic. If you want to build a binding for another
Rust UI framework, depend on `taino-dnd-core` directly.
